# CPP Modules

The C++ track of the 42 cursus: nine progressive modules (CPP00–CPP09) that build
up modern C++ fundamentals from the ground up, constrained to the C++98 standard.

Each module is a set of exercises with its own `Makefile`, compiled with
`-Wall -Wextra -Werror -std=c++98`.

## Modules

| Module | Focus |
|--------|-------|
| CPP00 | Namespaces, classes, member functions, stdio streams, initialization lists |
| CPP01 | Memory allocation, references, pointers to members, switch |
| CPP02 | Ad-hoc polymorphism, operator overloading, orthodox canonical form, fixed-point |
| CPP03 | Inheritance |
| CPP04 | Subtype polymorphism, abstract classes, interfaces |
| CPP05 | Repetition and exceptions |
| CPP06 | C++ casts (static / dynamic / reinterpret / const) |
| CPP07 | C++ templates |
| CPP08 | Templated containers, iterators, algorithms |
| CPP09 | STL — Bitcoin exchange, RPN calculator, Ford–Johnson merge-insertion sort |

## Build

Each exercise builds on its own:

```sh
cd cpp02/ex00 && make
```
